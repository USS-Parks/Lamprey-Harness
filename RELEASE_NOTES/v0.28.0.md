# Lamprey v0.28.0 — August 2026 catalog and Meta Muse

Released 2026-08-22.

## First-party catalog

- 82 pinned chat models. Twelve documented first-party ids released after the
  mid-July v0.27.1 roster are now selectable: DeepSeek V4 Flash Vision (exp),
  Gemini 3.7 / 3.6 Flash and 3.5 Flash-Lite, Qwen3.8 Max, GLM 5.3, Claude Opus 5,
  Claude Fable 5, Grok 4.6, MiniMax M3, and Muse Spark 1.2 / 1.1.
- Every new row uses the lab's published API id. No OpenRouter broker aliases.
  Anthropic rows still omit `reasoningCapOnToolUse` (the compat layer ignores it).

## Meta Model API

- New built-in provider `meta` at `https://api.meta.ai/v1`. Paste a Model API key
  (`LLM|…`) under Settings → API Keys → Frontier labs → Meta (Muse).
- Muse Spark 1.2 is the current hosted flagship; 1.1 is the earlier checkpoint
  and the key-test floor. The contributor training-data tier is not pinned.

## What stayed out

- Date-stamped DeepSeek 0731/0813 rows (same API ids as the existing V4 entries).
- Claude Mythos 5 (invite-only), Gemini 3.5 Flash Cyber (limited), `grok-4.6-fast`
  (not on xAI's table), `qwen3.8-27b` (no DashScope id), `glm-5.3[1m]` (5.3 is
  already 1M), Hy-MT2 (translation).
