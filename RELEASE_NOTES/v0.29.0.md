# Lamprey v0.29.0 — Audit Closure

Released 2026-08-22.

## Turns

- A tool-round cap settles `failed`, not `completed`. Cancel is `cancelled`.
- After a crash, Activity can show `orphaned: true` when the store still says
  running and no live runtime matches. Nothing auto-settles.
- `finalizeTurn` is the closer. Ordinary `chat:send` success no longer
  double-finalizes after `runHeadlessTurn`.

## Tools

- Dispatch lives in `electron/services/chat-tool-dispatch.ts`. Session tools
  (`memory_add`, plan mode, `ask_user_question`, `create_document`) run through
  registry handlers.
- Loop and Browser Developer packs are stripped from the model surface while
  their master toggles are off. Handlers stay fail-closed.
- Fallback parsing validates against the dispatch tool list for that round, not
  the full catalog.
- Unknown model ids and omitted custom `supportsTools` default to false.

## Catalog and gates

- `MODEL_CATALOG` and `RETIRED_MODEL_MAP` live in
  `electron/services/providers/catalog.ts`. No row edits this release.
- Pre-push runs `verify:proof` only when the pushed range touches product
  paths. Docs-only and ref-delete ranges print why and skip.
