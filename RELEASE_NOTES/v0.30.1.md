# Lamprey v0.30.1 — Tools + MCP Roster

Released 2026-08-23. Source wrap. Installer artifacts stay on v0.30.0
until a later Bucket.

## MCP catalog

- Curated Add-connector catalog is **ten** templates, parity-locked
  between `resources/connectors/catalog.json` and
  `src/data/connectors-catalog.ts`.
- Added Linear (`mcp-remote` → `https://mcp.linear.app/mcp`), Sentry
  (`@sentry/mcp-server` + `SENTRY_ACCESS_TOKEN`), Notion
  (`@notionhq/notion-mcp-server` + `NOTION_TOKEN`), Slack
  (`slack-mcp-server` + `SLACK_MCP_XOXP_TOKEN`).
- Replaced deprecated/404 packages: GitHub now uses the official Docker
  image; Postgres uses `@bytebase/dbhub`; SQLite uses
  `mcp-server-sqlite-npx`. Fetch was dropped (npm 404; the
  `mcp-server-fetch` name is a security holding package).
- Existing user `mcp-servers.json` entries are not rewritten.

## Native hygiene

- Skill-wizard allowed-tool hints are `CORE_SURFACE_NAMES` (shared
  export). The stale six-name list (`web_find`, `verify_workspace`) is
  gone.
- Inventory lock: after pack bootstrap every CORE name is registered;
  all 24 `tool-packs.ts` imports exist and call `registerNative`.
- OpenWiki `domains/tools/native.md` lists CORE + the pack map.
  `catalog.md` remains the **model** catalog.

## Non-goals held

- No new native tool capabilities.
- No `MODEL_CATALOG` edits.
- No plugin-tool runtime.
- No Bucket / installer rebuild in this wrap.
