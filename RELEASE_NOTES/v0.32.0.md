# Lamprey v0.32.0 — Reliability and verification repairs

This release repairs failures found during the September repository audit and production acceptance. The audit covers recent changes and older code still used by those paths. Findings, focused commits and verification receipts are recorded in `PLANNING/LAMPREY_SEPTEMBER_2026_REAUDIT.md` and its remediation PSPR.

## Runtime and data integrity

- Cancellation stops later tool dispatch, provider retries respond to abort, and application shutdown drains active turns and subagents.
- Unknown MCP tools and invalid arguments fail closed. Plugin connections, schemas, contribution loading and shutdown use consistent ownership.
- Compaction, task forks and backup restore preserve atomicity and recovery. Tool-call compression keeps complete result groups, and workspace access resolves real paths before allowing operations.
- Invalid configuration is preserved instead of silently overwritten. Settings persistence is serialized; model startup waits for the saved selection and exposes retry on failure.
- The production embedding worker is now packaged. Real quantized model inference, document ingestion and native vector retrieval execute end to end; vector keys and typed-array views are serialized correctly.
- Research synthesis rejects uncited output instead of presenting unsupported results as verified research.

## Usability and maintenance

- Restored plugin contributions, workflow execution/status navigation, PR controls and external attachment fallback.
- Fixed settings scrolling/focus, API-key error handling, modal Escape behavior, resize cleanup and browser-view lifecycle.
- Both environment panels now use a working commit dialog, preserve failed drafts, expose stale Git state and support retry. Subscription selectors avoid unrelated rerenders.
- Removed verified unreachable code and unused paths. Updated dependencies and replaced the retired Electron rebuild package; the recorded post-update npm audit reports zero advisories.
- Native database tests now execute under the correct Electron ABI and fail when required suites are skipped. Both TypeScript projects are checked explicitly; pre-push verification uses the actual pushed range.

## Release verification

Bucket waits for the exact tag workflow to finish, downloads its authoritative build artifacts, validates updater metadata, and verifies final GitHub/CDN bytes against one source-bound manifest. It no longer races a local Windows upload against CI. Partial publication and inaccessible or mismatched downloads fail the gate.

Source acceptance includes 3,007 passing default tests, all 170 native database tests, real Electron acceptance and exact-commit hosted CI/build evidence. Default skips are itemized in `PLANNING/evidence/SR34_SKIPS.md`; they are not counted as passing tests. Final publication hashes and installed-package smoke evidence are recorded by the release closeout.

Existing limits remain: not every hosted provider credential/playbook was exercised; macOS sandbox execution was not tested on the Windows acceptance host. Builds remain unsigned. No iOS package is provided.
