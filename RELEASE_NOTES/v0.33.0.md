# Lamprey v0.33.0 — Simpler daily work

This release rebuilds the desktop around one task, one conversation, and an optional workspace. Existing capabilities stay reachable. Existing permission, Steer, Queue and Stop rules are unchanged.

## What you will notice

- A task sidebar, conversation column and optional workspace replace the old eleven-card launcher as the daily path.
- The composer keeps text, attachments, a compact model picker and named permission/coding controls. Running turns still show one preferred follow-up action plus Stop.
- Settings are six searchable groups. Old section IDs and familiar names still open the same forms.
- Commands (`Ctrl+K`) find tasks, files, tools and settings by their old names.

## What did not change

- No claim of complete current-Codex feature parity.
- Builds remain unsigned. There is no iOS package. The Apple artifact is a macOS DMG.
- Auto-update follows GitHub. CDN/R2 closeout (TL-W4) stays open until GitHub, local `dist/` and CDN hashes match.
- Packaged install-smoke of these v0.33.0 bytes is recorded only after publication.

## Responsiveness

On the UX-00 Windows machine, warm task switch median p95 is 57 ms and loading feedback is 39.9 ms after the UX-34 repair. Idle typing median p95 is 77.4 ms; one run measured 100.5 ms.

## Downloads

Download URLs are filled when the GitHub release exists. Until then the published installers remain v0.32.0.
