macOS first launch

Lamprey is open source and not yet notarized with Apple, so macOS asks before the first run. Once, then never again:

  1. Open the DMG and drag Lamprey into Applications.
  2. Right-click Lamprey in Applications and choose Open, then Open again.
  3. If macOS still declines: open System Settings → Privacy & Security, scroll down, and press Open Anyway next to Lamprey.

Prefer the Terminal? This one line clears the first-launch prompt entirely:

xattr -cr /Applications/Lamprey.app

If you downloaded a DMG before v0.33.1 and saw “Lamprey is damaged and can’t be opened”, that build had a packaging defect — delete it and download again above.

Windows note

The installer is not yet code-signed, so SmartScreen may interject: choose More info → Run anyway. Auto-update keeps you current after that.
